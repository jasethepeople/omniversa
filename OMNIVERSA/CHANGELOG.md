# Changelog

All notable changes to OMNIVERSA will be documented in this file.

## [1.0.0] - 2024-05-10

### Added
- Initial release of the Hexagonal Coupling Architecture
- Six physics engines: CFD, Gravity, Hawkes, Neural, Narrative, Bayesian
- Unified Graph Topology (UGT) substrate
- Phase Space Manifold with Lyapunov divergence and principal component analysis
- Fragility Index with weighted fusion
- WebGPU 4D visualization pipeline
- Python orchestration layer with Ray/Dask
- Docker and Terraform deployment infrastructure
- gRPC and REST APIs
- Prometheus metrics and Grafana dashboards
- ClickHouse OLAP integration
- Full test suite and Criterion benchmarks
- GitHub Actions CI/CD pipeline

### Security
- AGPL-3.0 license to ensure open-source integrity of all deployments
