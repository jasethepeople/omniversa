# OMNIVERSA Architecture

## The Hexagonal Coupling

OMNIVERSA operates on six parallel engines, each modeling a different physical analogy of market behavior:

### 1. Liquidity CFD Engine (Viscosity)
- Scientific Basis: Navier-Stokes Equations
- Analogy: Liquidity as non-Newtonian fluid
- Key Metric: Cavitation risk

### 2. Gravity Whale Engine (Spacetime)
- Scientific Basis: N-Body Simulations (GADGET-4)
- Analogy: Capital pools as stellar masses
- Key Metric: Event horizon radius

### 3. Cascade Hawkes Engine (Seismology)
- Scientific Basis: Self-Exciting Point Processes / LAMMPS
- Analogy: Market crashes as tectonic failures
- Key Metric: Branching ratio

### 4. Neural Panic Engine (Biological)
- Scientific Basis: Hodgkin-Huxley Model
- Analogy: Market as global brain; panic as seizure
- Key Metric: Synchronization index

### 5. Narrative NLP Engine (Atmospheric)
- Scientific Basis: Latent Dirichlet Allocation / Transformer-GNNs
- Analogy: Sentiment as weather system
- Key Metric: Entropy bits

### 6. Bayesian Risk Engine (Observer)
- Scientific Basis: Hamiltonian Monte Carlo (Stan)
- Analogy: Quantum state observer
- Key Metric: Dark matter estimate
